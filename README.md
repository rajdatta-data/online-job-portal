# Online Job Portal

A web-based job portal built with PHP and MySQL, supporting three user roles: Admin, Company, and Candidate.

## Features
- Admin panel to manage users and job listings
- Company dashboard to post and manage jobs
- Candidate dashboard to search and apply for jobs
- Admin-mediated security for all registrations

## Tech Stack
- PHP, HTML, CSS, JavaScript
- MySQL (XAMPP)
- Bootstrap, jQuery, Font Awesome

## Setup Instructions
1. Install XAMPP and start Apache + MySQL
2. Import `database-mysql/demo1.sql` into phpMyAdmin
3. Configure DB credentials in the connection file
4. Place project in `htdocs` folder
5. Open `http://localhost/job portal/` in browser
